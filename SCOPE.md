## MVP
- Просмотр списка с arrétes с фильтрацией по дате, типу и органу выдачи.
- просмотр карточки конкретного arréte в расскрытом виде и ссылкой на источник.
- CRUD добавление и удаление arréte для авторизованных пользователей.
- Базовый рабочий интерфейс фронт + бэк + база данных  запущенные локально в контейнере без падений.
- Базовая регистрация и вход пользователя (user) и разгроничение прав (кто может менять данные)

## Not Now

- раздел с характеристиками оружия и экипировки полиции, классифицированное по категориям.
- автоматический парсинг сайтов для обновления arréte 
- Мобильное приложение.

## Definition MVP
- пользователь может зарегистрироваться, залогиниться, добавить arréte, обновить его, удалить, перезагрузить страницу - данные сохр. в БД.
- все эндпоинты API возвращают адекватные HTTP - статусы и валидируют некоректный ввод.
- код залит в репозиторий - секретов и ключей в репозитроии нет.
